# Contributing to Mayo Clinic Patient Portal

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.

## How to Contribute
1. Review open issues and feature requests.
2. Discuss major changes in an issue before submitting a PR.
3. Ensure your code is well‑documented and tested.

## Reporting Issues
- Use the GitHub Issues tab.
- Provide clear steps to reproduce.
- Include screenshots or logs if relevant.

## Suggesting Features
- Open a feature request issue.
- Explain the problem and how your idea solves it.
- Suggest implementation details if possible.

## Code of Conduct
- Be respectful and inclusive.
- No harassment or discrimination.
- Collaborate constructively.

## Review Process
- PRs are reviewed by maintainers.
- Feedback will be provided for improvements.
- Once approved, changes are merged into the main branch.
